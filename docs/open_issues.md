# 待办与目标（2026-11-27）

## 老师的目标（原文意思）

> 渲染图直接放进千问，特征利用不全。希望能组合一些深度网络，
> 在物理指数渲染图基础上补充视觉特征图，再由大模型做多模态协同分类。
> 另外最好有语义特征（可以试 CLIP），最后输入大模型的是物理特征、视觉特征、语义特征，
> 由大模型综合分析。

## 当前已经做到

- 物理：指数渲染图（baseline，未动）
- 视觉：ResNet50 嵌入 + 每元素线性探针
- 语义：CLIP 嵌入 + 每元素线性探针（CLIP 零样本文本相似度对渲染图无效，已证伪）
- 协同：决策级融合（Qwen 判读 + 探针高置信覆盖，tau 0.6）
- 证据：同分布 9 元素 8 升 1 平；训练集外 3 元素 2 升 1 平
- 已证伪：文本注入（拖累）、图像级拼图（破坏判读）
- 开关：`configs/fusion_selected.yaml` 按元素启用

## 未解决（按优先级）

1. **全量覆盖**：38 个元素的探针训练与验证（进行中；当前 12 个元素验证过融合）
2. **外部日期覆盖**：目前只有 wave / groundwater / earthquake / snow_fsc 有训练集外样本
3. **projector / token 级融合**：把视觉、语义向量通过 projector 接进 Qwen 输入序列，
   才算“特征真正送入大模型内部”。需要训练，8GB 显存可行但周期长
4. **大模型语义未真正参与**：现在 Qwen 只做基础判读，语义信息在输出层协同；
   文本注入被证伪，说明需要 projector 才能让模型“看见”语义
5. **DINOv2 支路**：接口留了，尚未接入实测
6. **逐元素质量提升**：弱 sev 元素（wind_gale、flood_water、coastal_nt 等）还需要按元素处理

## 建议顺序

1. 先跑完 38 元素探针（CLIP → ResNet），产出逐元素准确率表
2. 按“探针明显高于 baseline sev”筛出获益元素，写进 fusion_selected
3. 补 3–5 个弱元素的外部日期样本，做诚实复核
4. 再做 projector 端到端版本
5. 最后按元素抠质量

## 约束

- Qwen 权重、baseline 结果一律不动
- 任何融合结论必须区分“同分布”和“训练集外日期”
- 不把探针在同日期验证集上的高分当泛化证据
