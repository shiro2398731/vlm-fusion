## 单元素处理流程（固定五步）

1. 取该元素验证集与留出集，跑混淆矩阵（哪些等级互相混）
2. 抽查误判图，判因：标签边界噪声 / 视觉不可分 / 模型读不出
3. 若主要是标签边界 → 只复核阈值，不重训
4. 若确实是模型问题 → 只重训该元素：加等级边界样本、按类均衡采样
5. 同分布 + 留出各重测一次，记录提升；达不到就记录“上限在哪、为什么”
