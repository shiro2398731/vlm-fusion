# 论文方法草稿：三路特征协同的遥感灾害判读

（基于 vlm-fusion 实现；与 vlm 基线的对比数据见仓库文档）

## 1 任务定义

每个元素由三元组定义：灾种/致灾因子 × 数据源 × 判读任务。
输入为原始产品渲染后的物理指数图 $I$ 与窗口物理统计量 $s$，
输出为结构化判读 $y=(detected, severity, source, physical\_quantity, value, criterion)$。

基线：Qwen3-VL-4B-Instruct（4bit）+ 每个元素一个 rank-4 LoRA 挂件，
直接读取 $I$ 生成 $y$。基座与挂件在本文实验中保持不变。

## 2 三路特征

对每个样本提取三路特征：

1. **数值特征**：窗口物理统计量 $s$（如平均积雪覆盖率、最大 SLA），
   由渲染前的原始产品直接计算，不经模型估计。
2. **视觉特征**：冻结 ResNet50（或 DINOv2）对 $I$ 编码，
   取全局嵌入 $v$，并在该元素的训练集上训练线性探针，得到类别概率
   $p_v = \mathrm{softmax}(W_v v + b_v)$。
3. **语义特征**：冻结 CLIP 图像编码器得到嵌入 $c$，
   在同一训练集上训练线性探针，得到类别概率
   $p_c = \mathrm{softmax}(W_c c + b_c)$。

注：CLIP 零样本文本相似度在本任务上无效（渲染图为伪彩色指数图，
实测 coral top-1 0%、snow_fsc 31%），因此语义特征采用“嵌入 + 探针”形式。

为把特征信息显式送入基座，对 $v$ 与 $c$ 做 PCA 压缩到 16 维，
记作 $\hat v, \hat c$，与概率、数值一起拼成输入文本：

```
Physical statistics: s
Visual scores: p_v
Visual feature vector (16 dims): \hat v
Semantic scores: p_c
Semantic feature vector (16 dims): \hat c
```

三路信息与图像 $I$ 一起送入 Qwen3-VL，由基座输出判读 $y$。

## 3 决策级融合

文本注入与图像拼图两种融合方式实测会拖累判读（见实验记录），
因此采用决策级规则：

$$
y_{final} =
\begin{cases}
\arg\max_k\ p_c(k), & \max_k p_c(k) \ge \tau \\
y_{Qwen}, & \text{otherwise}
\end{cases}
$$

其中 $p_c$ 为该元素选择的探针（CLIP、ResNet 或 DINOv2），$\tau=0.6$。
阈值扫描 0.5/0.6/0.7 显示 0.6 最稳。

同时保留文本级与图像级实现作为消融对照。

## 4 数据与评测

- 元素：38 个（10 类获取方式）
- 切分：样本级确保测试图不在训练集；日期级单独核查
- 指标：det 准确率、severity 准确率、数值字段 MAE
- 对照：baseline / +视觉 / +语义 / +视觉+语义；决策融合另做 CLIP 与 DINOv2 两版

## 5 结果摘要

- 三路特征向量附加：coral 上 +both 5/6→6/6；语义向量在部分元素有干扰
- 决策融合（最优探针，38 元素）：**26 升、12 平、0 降**
- 训练集外日期：wave 2/8→5/8（DINOv2）、earthquake 4/6→6/6、groundwater 持平；
  snow_fsc 外部 baseline 8/8，融合关闭
- 逐元素配置：38 元素中 25 个启用融合（`configs/fusion_best.yaml`）
