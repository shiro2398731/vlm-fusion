## 5 服务与接口

| 项 | 值 |
|---|---|
| 服务 | `uvicorn scripts.serve:app --host 127.0.0.1 --port 8078` |
| 健康检查 | `GET /api/status` |
| 元素列表 | `GET /api/elements` |
| 判读 | `POST /api/predict`（multipart：file、element、extra_text） |

服务需要的环境变量：

```
VLM_MODEL       Qwen3-VL 权重目录
VLM_OUTPUTS     LoRA 挂件目录（默认 <repo>/outputs）
VLM_LF_DATA     训练/验证 JSON 目录
VLM_CAPABILITY  elements_capability.json
VLM_APPENDIX    论文附录元素表（可选）
```

## 6 可配置的远程后端

| 后端 | 配置 | 说明 |
|---|---|---|
| 语义支路远程 | `semantic.extractor: clip_api` + `base_url/api_key/model` | POST 图片 base64，返回 `{embedding}` 或 `{scores}` |
| 判读 LLM 远程 | `llm.backend: api` + `base_url/api_key/model` | OpenAI 兼容 `/chat/completions`，图片走 base64 data URL |

环境变量：`SEMANTIC_API_URL`、`SEMANTIC_API_KEY`、`LLM_API_KEY`。

## 7 渲染与判读约定

- 渲染图：固定色标、384×384、PNG
- 每元素提示词：取训练 JSON 第一条 human 文本（去掉 `<image>`）
- 输出：JSON（disaster_type / detected / source / physical_quantity /
  severity / 数值字段 / criterion）

## 8 复现实验的最短路径

```bash
# 1. 起服务（本地）
uvicorn scripts.serve:app --port 8078

# 2. 探针（已完成，可重训）
python scripts/train_clip_probe.py <elements>
python scripts/train_resnet_probe.py <elements>
python scripts/train_dinov2_probe.py <elements>

# 3. 配置与验证
python scripts/gen_best_config.py
python scripts/validate_best_config.py

# 4. 评测
python scripts/eval_decision_fusion.py <elements>
python scripts/eval_four_groups_element.py <element>
```
