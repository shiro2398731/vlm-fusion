# 弱元素处理记录

## snow_swe（severe 低估）

- 原始链路 baseline 2/6，决策融合 2/6
- 验证集 75 条：baseline sev 58/75（77.3%），模型读数 MAE 6.33 mm
- 线性校准：truth ≈ 1.066 × pred + 1.073，校准后 MAE 6.39（无改善）
- 结论：读数无系统偏差，heavy 训练样本仅 3 个，属少样本问题
- 解法：探针融合（探针验证 89.3% > baseline 77.3%），不做数值校准

## ground_subsidence / groundwater_overuse（InSAR 数值判读）

- 原始链路两元素各 2/4；明显沉降窗口被模型判成 stable，模型 median_mm 输出 0
- 决策融合在配置中关闭（同分布融合会下降）
- 结论：渲染图 + 挂件对 InSAR 位移量读数不可靠，需要重训挂件或数值规则化
- 状态：保持 baseline，待按元素重训

## wind_gale / wave / hurricane_opt（探针选择）

- 原始链路对比：wind_gale CLIP 4/4 vs DINOv2 2/4；wave CLIP 3/3 vs 2/3；
  hurricane_opt CLIP 2/2 vs 1/2
- 处理：三元素均改回 CLIP 探针（fusion_best 已更新）
