## 2 架构

```
原始产品 → 渲染（固定色标 384×384）→ 物理指数图 + 物理统计量
        ├─ 数值支路：统计量归一化
        ├─ 视觉支路：ResNet50 / DINOv2 → 每元素探针 → 概率 + PCA-16 向量
        └─ 语义支路：CLIP → 每元素探针 → 概率 + PCA-16 向量
                    ↓ 融合层（文本 / 图像 / 决策级）
        Qwen3-VL-4B（4bit + 每元素 rank-4 LoRA，未改）
                    ↓
    结构化 JSON + LLM 研判 + 逆地理编码
```

融合采用决策级：探针最高概率 ≥ tau(0.6) 时覆盖 Qwen 等级，否则保留 Qwen。
