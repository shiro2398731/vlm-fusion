# 账号注册与配置

> 仓库里所有凭据位置都是**空白**的。要下载数据，需自己注册对应平台账号并把凭据填进
> `scripts/config_local.py`（或设同名环境变量）。

## 1. 哪个元素需要哪个账号

| 平台 | 免费注册 | 用于元素 |
|---|---|---|
| NASA Earthdata | https://urs.earthdata.nasa.gov/users/new | MODIS NDVI/LST/大气、GPM/IMERG 降水、SMAP 土壤水分、OMI SO₂、Sentinel-1（ASF） |
| Copernicus CDSE | https://dataspace.copernicus.eu/ | Sentinel-1/2/3（光学、SAR、海冰、火山、绿潮等） |
| NSIDC | https://nsidc.org/ | AMSR2 海冰/积雪（部分产品需登录） |
| NASA FIRMS | https://firms.modaps.eosdis.nasa.gov/api/ | 火点（需申请 MAP_KEY，免费） |
| CMEMS | https://data.marine.copernicus.eu/ | 海面高度 SLA、海面风场（部分产品匿名可下） |
| NOAA SWPC / GFZ | 无需注册 | 太阳耀斑、地磁 Kp |

## 2. 配置方式

编辑 `scripts/config_local.py`（该文件已入库，内容全空）：

```python
EARTHDATA_USER = "你的 Earthdata 用户名"
EARTHDATA_PASS = "你的 Earthdata 密码"
EARTHDATA_TOKEN = "你的 Earthdata token"   # 推荐，比密码稳
CDSE_USER = "你的 CDSE 邮箱"
CDSE_PASS = "你的 CDSE 密码"
```

或使用环境变量（优先级更高，适合临时/多机）：

```powershell
$env:EARTHDATA_TOKEN = "..."
$env:CDSE_USER = "..."
$env:CDSE_PASS = "..."
```

## 3. 各平台怎么拿凭据

### Earthdata（最常用）

1. 打开 https://urs.earthdata.nasa.gov/users/new 注册（邮箱验证）
2. 登录后点右上角头像 → **Generate Token**，复制 token
3. 首次访问某些产品需在 **Applications → Authorized Apps** 里勾选对应 DAAC（如 GES DISC、NSIDC、PO.DAAC）

### Copernicus CDSE

1. 打开 https://dataspace.copernicus.eu/ 注册（邮箱 + 密码）
2. 用同一邮箱密码填 `CDSE_USER` / `CDSE_PASS`
3. 若提示账号未激活，去邮箱点确认链接

### FIRMS（火点）

1. 打开 https://firms.modaps.eosdis.nasa.gov/api/ 申请 **MAP_KEY**（填邮箱，立即下发）
2. 仓库的 `download_firms_cn.py` 通过参数或环境变量 `FIRMS_MAP_KEY` 读取

### NSIDC

1. 注册 Earthdata 账号并在 Earthdata Profile 里关联 NSIDC
2. AMSR2 部分产品可直接匿名下载，遇到 401 再登录

## 4. 验证凭据

```powershell
# Earthdata：拉一个 GPM 小文件测试
python scripts/download_gpm.py --help
python scripts/download_imerg_flood_days.py --help

# CDSE：查一次 Sentinel-2 元数据
python scripts/download_sentinel2.py --help
```

如果返回 401/403：

- 401：用户名/密码/token 错，或应用未授权（回第 3 步）
- 403：账号未激活，或产品权限未勾选
- token 过期：重新 Generate Token

## 5. 不需要账号的部分

以下可以直接跑，不需要任何凭据：

- 演示服务、自检、评估、质量审计
- 逆地理编码（边界数据已入库）
- 太阳耀斑/地磁（公开数据已入库）
- 渲染器（`src/preprocess/`，输入是已下载的原始数据）
