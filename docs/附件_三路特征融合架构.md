# 附件：多模态三路特征融合架构

（vlm-fusion 仓库；配套 vlm 基线版本使用）

## 1 背景与目标

基线做法：把物理指数渲染图直接送入 Qwen3-VL，按元素 LoRA 挂件输出结构化判读。
问题：渲染图只承载物理量，模型能用的视觉信息有限。

本附件记录在此基础上的扩展：组合深度网络，为每个样本补充视觉特征与语义特征，
与数值特征一起作为输入交给 Qwen 做多模态协同分类。Qwen 基座权重与基线挂件均未改动。

## 2 总体架构

```
                 ┌──────────────────────────────┐
                 │ 物理支路                      │
                 │ 指数渲染图 + 每样本物理统计量   │
                 └──────────────┬───────────────┘
                                │
   ┌────────────────────────────┼────────────────────────────┐
   │                            │                            │
┌──▼───────────────┐  ┌─────────▼──────────┐  ┌──────────────▼────────┐
│ 视觉支路          │  │ 语义支路            │  │ 数值支路                │
│ ResNet50 / DINOv2 │  │ CLIP               │  │ 物理量归一化            │
│ 每样本特征与向量   │  │ 每样本特征与向量     │  │ 特征与向量              │
└──┬───────────────┘  └─────────┬──────────┘  └──────────────┬────────┘
   │                            │                            │
   └────────────────────────────┼────────────────────────────┘
                                ▼
                     ┌─────────────────────┐
                     │ 融合层（可配置）      │
                     │ 文本 / 图像 / 决策级  │
                     └──────────┬──────────┘
                                ▼
                     ┌─────────────────────┐
                     │ Qwen3-VL 基座        │
                     │ 多模态协同分类        │
                     └──────────┬──────────┘
                                ▼
              结构化 JSON + LLM 研判 + 逆地理编码
```

## 3 三路特征的定义

| 支路 | 深度网络 | 每样本输出 | 进入模型的形式 |
|---|---|---|---|
| 视觉 | ResNet50 / DINOv2（冻结） | 类别概率 + 特征向量 | 分数 + PCA-16 向量摘要 |
| 语义 | CLIP（冻结） | 类别概率 + 特征向量 | 分数 + PCA-16 向量摘要 |
| 数值 | 无 | 物理统计量 | 归一化数值 |

说明：

- 视觉与语义探针为各元素单独训练的线性分类头（分钟级），不重训 Qwen。
- CLIP 零样本文本相似度对渲染图无效（实测 coral top-1 0%、snow_fsc 31%），
  故语义支路采用「CLIP 嵌入 + 探针」形式。
- 每样本的原始特征向量经 PCA 压到 16 维后以数字形式写入输入；
  如需更高保真可改为 projector 接入（未实现，列为后续）。

## 4 融合方式与取值

| 模式 | 做法 | 结论 |
|---|---|---|
| A 文本级 | 三路分数与向量写进 prompt | 部分元素拖累，默认关闭 |
| B 图像级 | 视觉特征图并排/叠加 | 破坏挂件判读（snow_swe 3/8→1/8 或 2/8），关闭 |
| C 决策级 | Qwen 判读 + 探针高置信覆盖（tau 0.6） | 采用 |
| D 嵌入级 | projector → token | 未实现 |

决策级规则：探针最高概率 ≥ tau 时用探针等级覆盖 Qwen 等级，否则保留 Qwen 判读。
tau 扫描 0.5/0.6/0.7：0.6 最稳；flare 对 0.7 敏感。

## 5 实验设置

- 数据：各元素验证集，按类别每类取 2 张（同分布对照）
- 训练集外：wave、earthquake_def、groundwater_overuse 的验证集本身即训练集外日期
- 指标：det 准确率、sev 准确率、数值平均绝对误差（MAE）
- 四组：baseline / +视觉 / +语义 / +视觉+语义

## 6 结果

### 6.1 决策级融合（32 元素，同分布）

提升 18 个、持平 13 个、下降 1 个（green_tide 5/6→4/6，已关闭）。

显著提升示例：

| 元素 | baseline | 融合 |
|---|--:|--:|
| flood_precip_global | 2/8 | 7/8 |
| hurricane_rain | 2/8 | 7/8 |
| flare | 2/8 | 6/8 |
| haze | 2/6 | 6/6 |
| wildfire | 0/4 | 4/4 |
| gpm_nt | 3/6 | 6/6 |
| sea_ice_amsr2 | 3/8 | 6/8 |
| wildfire_smoke | 3/8 | 6/8 |

### 6.2 训练集外日期

| 元素 | baseline | 决策融合 |
|---|--:|--:|
| wave | 2/8 | 3/8 |
| earthquake_def | 4/6 | 6/6 |
| groundwater_overuse | 4/6 | 4/6 |
| snow_fsc（baseline 8/8） | 8/8 | 关闭融合 |

### 6.3 三路特征向量的影响（coral_dhw，6 张）

| 配置 | baseline | +视觉 | +语义 | +both |
|---|--:|--:|--:|--:|
| 只给概率 | 5/6 | 5/6 | 6/6 | 5/6 |
| 附两路向量 | 5/6 | 6/6 | 5/6 | 6/6 |
| 只附视觉向量 | 5/6 | 6/6 | 6/6 | 6/6 |

结论：视觉向量有正收益；语义向量在部分元素上会造成干扰，按元素开关。

## 7 配置说明

`configs/fusion_selected.yaml`：逐元素开关，由实测结果生成（35 元素中 21 个启用）。
`configs/fusion.example.yaml`：逐元素配置样例，含三路开关、融合模式、tau。

## 8 限制与后续

1. 训练集外日期仅覆盖 4 个元素，其余为同分布验证。
2. 语义向量在部分元素负收益，需按元素校准。
3. projector / token 级融合未实现，当前语义与视觉向量以数字文本进入模型。
4. 弱 sev 元素仍可按元素继续调探针与阈值。
