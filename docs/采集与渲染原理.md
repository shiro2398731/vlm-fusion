# 采集与渲染原理

> 每个元素「卫星测什么 → 怎么画成图 → 怎么看图判灾」的技术说明；判据原文取自训练数据。

## 0. 一句话总述

卫星不直接「看灾害」，它测的是**物理量**（反射率、亮温、亮温差、重力、海面高度、风场）。
我们先把物理量渲染成**带色标的指数图**（色标即图例），再让模型读图输出「有没有灾 / 多重 / 判据」。
所以模型判断的依据是**图上颜色对应的物理量**，不是照片里的纹理。

## 1. 十类源：采集 → 渲染 → 判读

### 光学 OPT（Sentinel-2 / MODIS）

- **采集原理**：太阳光被地表反射，传感器测可见-近红外反射率 ρ。水体在近红外强吸收，所以 NDVI=(NIR−R)/(NIR+R) 变低、NDWI=(G−NIR)/(G+NIR) 变高；积雪 NDSI=(G−SWIR)/(G+SWIR) 高；藻类 FAI 在红边抬升。
- **渲染原理**：把指数归一化到固定区间（如 NDWI −1..1）用固定色标渲染：水→蓝、植被→绿、雪→白。洪水元素还会叠加低 NDVI 掩膜，避免把裸地当水。
- **从图判读**：看蓝色面积占比：占比 >20% 判内涝/洪水；蓝色越深越大，强度越高。绿潮看绿色藻带面积，水华看叶绿素浓度色阶。
- **本仓库元素**：flood_opt、green_tide、drought_ndvi_clim、snow_fsc、bloom_chla、sea_ice_s2_arctic、hurricane_opt

### 热红外 TIR（MODIS LST / OISST）

- **采集原理**：地表按普朗克定律发射热辐射，传感器测 10–12 μm 亮温 T_b（K），用分裂窗订正成地表温度 LST（℃）。热浪用「当日 LST − 气候态」的距平或百分位；海温 SST 同理。
- **渲染原理**：距平图用发散色标（红正、蓝负、0 为白）；绝对温度用连续色标。色标两端写数值，图上直接可读。
- **从图判读**：看红色区域与距平数值：距平 > +5 K 且面积大 → 热浪；负距平 → 霜冻；孤立极亮点位 → 火山热异常/野火。
- **本仓库元素**：heatwave_lst、frost、volcano_thermal、wildfire、iod、mhw、coral_bleaching、enso

### 被动微波 MW（SMAP / AMSR2）

- **采集原理**：微波亮温对**介电常数**敏感，而介电常数随含水量变化：L 波段（1.4 GHz）穿透植被测土壤水分；18/36 GHz 对雪粒散射敏感，反演积雪当量 SWE；海冰与海水发射率差异大，反演密集度。
- **渲染原理**：土壤水分渲染成体积含水或百分位（0–100%）；积雪渲染成 SWE（mm）；海冰渲染成密集度（%）。
- **从图判读**：土壤水分百分位 >90% → 内涝；SWE 高且范围大 → 暴雪/积雪；密集度 >15% 视为有冰。
- **本仓库元素**：waterlogging_pct、snow_swe、sea_ice_amsr2、blizzard

### 雷达降水 PRECIP（GPM / IMERG）

- **采集原理**：GPM 的 DPR 雷达测雨滴后向散射，GMI 微波辐射计测亮温，联合反演降水率 R（mm/h）；IMERG 融合多源做 30 分钟到月尺度产品，我们取日/多日累计。
- **渲染原理**：累计降水用对数色标（蓝→绿→黄→紫），图上标 mm 刻度。
- **从图判读**：看累计值与面积：24 h > 50 mm 为暴雨；重复出现在同一区域且累计 >100 mm → 洪水/台风降水。
- **本仓库元素**：rainstorm、flood_precip_global、typhoon_precip

### 测高 ALT（卫星高度计）

- **采集原理**：雷达高度计测「卫星到海面」的时间，得到海面高度 SSH = 轨道高度 − 测距 − 各项改正；SLA = SSH − 多年平均海面。波形上升沿还能反演有效波高。
- **渲染原理**：SLA 渲染成 cm 发散色标；波高渲染成 m 连续色标。
- **从图判读**：SLA 正异常（红）叠加近岸 → 海岸高水位；波高 >4 m（或历史高分位）→ 巨浪。
- **本仓库元素**：coastal_sla、coastal_nt、wave

### 重力 GRACE（GRACE / GRACE-DA）

- **采集原理**：两颗卫星间距的微小变化反映重力场变化，去球谐展开后得到**等效水高 EWH**（cm）：总水储量（地下水+土壤水+雪+地表水）的柱积分。
- **渲染原理**：EWH 渲染成距平或百分位（相对气候态），发散色标。
- **从图判读**：持续负距平（蓝）→ 地下水超采/干旱；正距平 → 洪涝或冰雪积累。注意 GRACE 分辨率约 300 km，只能看区域趋势。
- **本仓库元素**：drought_grace、groundwater_overuse

### SAR（Sentinel-1）

- **采集原理**：雷达主动发射微波，测后向散射 σ⁰（VV/VH）：平静水面镜面反射→暗，粗糙地表→亮。干涉（InSAR）用两景相位差测形变，精度毫米级；相干性衡量两景一致性。
- **渲染原理**：形变速率渲染成发散色标（蓝抬升、红沉降，mm/yr）；洪水用后向散射图（水面暗）。
- **从图判读**：|沉降速率| > 10 mm/yr 且连片 → 地面沉降；相位突变环 → 地震形变；暗区面积 → 洪水范围。
- **本仓库元素**：earthquake_def、groundwater_overuse、ground_subsidence、flood_water

### 大气 ATM（OMI / MOD08）

- **采集原理**：气溶胶和 SO₂ 吸收/散射太阳紫外-可见光，用 DOAS 反演柱浓度：UVAI（吸收性气溶胶指数）判别沙尘/烟羽；SO₂ 柱量单位 DU。
- **渲染原理**：UVAI 连续色标（0–3+）；SO₂ 用 DU 色标；AOD 无量纲。
- **从图判读**：UVAI >1 且成片 → 沙尘/烟羽；SO₂ >5 DU 且形态集中 → 火山喷发；AOD 高 + 低能见度 → 霾。
- **本仓库元素**：wildfire_smoke、dust_aerosol、volcano_so2、dust_storm、haze

### 散射计 SCAT（ASCAT / 散射计）

- **采集原理**：海面风生粗糙度改变后向散射，散射计多角度观测反演 10 m 风速与风向。
- **渲染原理**：风速渲染成 m/s 连续色标。
- **从图判读**：风速 ≥17.2 m/s（8 级）→ 海上大风；≥24.5 m/s 为强热带风暴级。
- **本仓库元素**：wind_gale

### 空间天气 SPACE（NOAA SWPC / GFZ）

- **采集原理**：GOES XRS 测 0.1–0.8 nm 软 X 射线通量（W/m²），按峰值分 C/M/X 级；地磁用地面台站磁场扰动算 Kp 指数。
- **渲染原理**：耀斑渲染成通量时间曲线（对数轴）或等级色条；地磁渲染成 Kp 色条。
- **从图判读**：XRS ≥1e-5 W/m² → M 级耀斑；≥1e-4 → X 级。Kp ≥5 → 地磁暴（G1 起）。
- **本仓库元素**：flare、geomagnetic
